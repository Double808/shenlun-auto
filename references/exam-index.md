# 申论真题知识库索引

## 匹配规则

1. 从用户输入的文字内容中提取实体词（地名、机构名）、主题词（反复出现的核心概念）、结构词（"第X题""XX分"）
   - 用户发来图片（试卷照片/截图）时，**先按 `SKILL.md` Step 2 完成图片识读并转写为文字**（详见 `image-reading-rules.md`），再从转写文本中提取关键词
2. 将提取的关键词与下表中每行的"主题关键词"列做交集比较
3. 按重叠数量判定（**【本 skill 覆盖】全程静默，不打断批改、不向用户确认**）：
   - **>=3 个关键词重叠** → 高置信度匹配，加载对应真题文件，并在报告「识别与假设」中标注命中依据
   - **1-2 个关键词重叠** → 中等置信度，仍按该真题采分点为基准，但在报告中标注「疑似 XX 年 XX 卷，匹配置信度中」
   - **0 个关键词重叠** → 未匹配。**不要向用户索取题干**：按 `SKILL.md` Step 3 用材料关键词反推题型并照常批改，报告标注「未匹配真题，采分点为现场拆解」；确需按通用文章评改处理时走 `fallback-eval-rules.md`
4. **采分点缺失降级**：命中真题但对应题目的「阅卷采分点」为 `[待补充]` 或整题未收录时，视为「命中但无基准」——按给定材料**现场拆解采分点**，报告中标注「命中真题，采分点未收录，已降级为现场拆解」，**不得把空占位当作无点可给**
