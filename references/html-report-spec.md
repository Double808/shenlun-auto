# HTML 阅读版报告规范

## 一、定位与触发

- `.md` 是**归档与数据源**（错题库统计、复核、Git 追踪都基于它），`.html` 是**阅读版**，两者同名并存于 `申论批改/`
- Step 7 归档时**双输出为默认行为**：`<日期>-<题型>-<短标题>.md` + 同名 `.html`
- 模板：`templates/report-template.html`。复制全文 → 按 `{{占位符}}` 填充 → 写入工作区
- 宿主不支持写 HTML 时跳过并在报告末尾注明，不因此中断批改

## 二、硬性约束

1. **单文件自包含**：CSS 已内嵌于模板，禁止引入外部资源（CDN、外链图片、外链字体）
2. **UTF-8 编码**，`lang="zh-CN"`
3. **样式语义固定，不得改**：
   - 绿 `hit/p-full/ok` ＝ 全踩/达标
   - 黄 `part/p-part/warn` ＝ 半踩/存疑/超时
   - 红 `miss/p-miss/bad` ＝ 漏点/撤回/错误
   - 紫 `d-purple` ＝ 错位型偏差
   - 灰 `na/d-gray` ＝ 冗余/非采分点
4. **颜色只表达判定状态**，不用作装饰；没有对应判定的元素用默认色
5. **头部得分框按得分率选类**：≥70% 用 `score-box ok`（绿）、60–69% 用 `score-box warn`（黄）、<60% 用 `score-box bad`（红）；不得一律用红色

## 三、章节规则

| 区块 | 规则 |
---|---|
| 头部得分框 | 得分放头部（阅读版例外于"分数放最后"的 md 规则，因 HTML 可滚动导航；md 版分数仍在 ⑦） |
| 指标条 | 四格固定：得分率 / 稿纸占格 / 采分覆盖 / 用时；用时未提供则该格显示"—" |
| 手写转写 | **忠实转写全文必须进 HTML**；存疑字用 `<mark class="q">` 原位高亮；三格元数据（条数涂改 / 占格 / 双通道偏差） |
| 答案骨架 | 每条作答一行：条号/概括词/主语/覆盖点/状态/占格；主语列直接标"自拟词""多主语"等问题 |
| ② 采分点卡 | 每点一张卡，**四层固定**：📄材料原文 → ⬆上位概括 → ✍你的原话 → 判定；一个点含多个发声主体时，主体各占一组三栏行；未写处红字"未写" |
| ③ 偏差卡 | 红/橙/紫/灰分色；每卡内"你的思路 vs 正确思路"左右对照 |
| ④ 决策 | `<details>` 折叠，默认收起；每处必须有判据 |
| ⑦ 参考作答 | 两版左右对照；**复核撤回的点在原位 `<del>` 划线 + 撤回徽标**，并在卡内说明撤回原因——防止用户背进错误点 |
| 错题库趋势 | 次数徽章 ≥5 红、≥3 橙、2 黄、1 灰；末尾必带下次验收标准 |

## 四、生成后自检（不过则修复后再落盘）

- [ ] 无 `{{ }}` 占位符残留
- [ ] 无 HTML 实体残留（如 `&#x` 开头的乱码）与标题尾缀噪声
- [ ] `<div>` 开闭数量一致；表格行列对齐
- [ ] 存疑字高亮、撤回点划线、颜色语义与判定一致
- [ ] 与同名 `.md` 的得分、采分点数、偏差类型**逐项一致**（两版数据来自同一次批改，不允许出现口径差）
