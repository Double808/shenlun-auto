# 手写申论格纸识读细则

适用：用户拍摄的手写作答照片（手机拍摄、扫描件、翻拍均适用）。
目标：**从一张照片里同时拿到三样东西**——作答文字、字数、版面问题。前两样决定分数，第三样决定改进建议。

---

## 一、先认纸：判断格纸规格

申论稿纸常见三种，**规格决定字数算法**：

| 规格 | 特征 | 每行格数 |
|---|---|---|
| 标准申论稿纸 | 红色/绿色方格，行末有字数标记（每 100 字标注） | **25** |
| 答题卡方格区 | 黑色方格，无字数标记，四周有框 | 20 或 25（须数） |
| 横线纸 | 只有横线无竖格 | 按每行**字数估算**，精度下降，须标注 |

**操作**：先数一行有几格。数不准就看行末是否有"100/200/300"的累计字数标记——有标记说明每 4 行 100 字，即 **25 格/行**。

> 若完全无法确定格数 → 字数标为「约 X 字（估算）」，且**不因超字数扣分**（依据不足）。

---

## 二、按格转写（不是按行转写）

### 为什么必须按格

按行转写会丢掉三样关键信息：
1. **字数**——行末未写满时，只有按格才知道占了几格
2. **缩进**——首行缩进两格是格式分依据
3. **版面**——段落划分、是否分条、条与条之间是否空行

### 转写顺序

```
逐页 → 逐行 → 逐格
每行产出：[格1][格2]...[格25]  → 拼接为该行文本 + 已用格数
```

**边界处理**：
- **行首缩进**：前两格空白视为缩进，计入字数（申论评分按格计字，缩进占格）
- **行末未满**：数实际占用格数，不按 25 计
- **换行处断词**：一个词被拆到两行，转写时**合并**（不影响语义），但字数仍按两行格数计
- **跨页**：上一页末行与下一页首行按语义衔接；页眉页脚、装订线**不计入**

### 题号与题目分界

一份答卷多题时，按「一、」「二、」「第1题」「（1）」等标记切分。
**切不准时**：看内容主题是否跳变（如从"问题"跳到"对策"），仍切不准则该段归入前一题并在报告中说明。

## 三、涂改三类，三种处理

手写作答必然有涂改。**不同涂改方式，法律地位完全不同**：

| 类型 | 外观 | 处理 |
|---|---|---|
| **划线删除** | 单横线/双横线划过文字，字仍可辨 | **不计入字数、不计入作答**。若划线后有重写，以重写为准 |
| **涂黑覆盖** | 墨团、反复涂抹，字不可辨 | 不计入字数、不计入作答。**若无法判断原本写的是什么，不得推测内容** |
| **旁注补充** | 页边、行间插入的小字，常有箭头或"△"标记 | **计入作答**（阅卷时有效），但字数**不计入格数**，须单独加总并标注 |

**争议情形**：
- 划线后**没重写** → 视为删除，该点不得分，但**在报告中提示"此处删除后未补写，可能是漏点"**，这是改进点而非扣分点
- 涂改处**上下文能推断原意** → 可推断，但必须标 `[涂改处，据上下文推断]`，且该条**不据此扣分**

## 四、字数推算（核心公式）

```
正文占格数 = Σ（每行实际占用格数）
总占格数   = 正文占格数 + 旁注折算字数
```

- 每行实际占用格数 = 该行写到的最后一格（含标点、序号、行首缩进两格；行末未满按实际格数）。
- 旁注（页边/行间插入的小字）计入作答但**不占格**，单独折算字数后相加，并标注。

**计入**：标点（每个占 1 格）、行首缩进、序号（"一、""1."）、数字（按格数，如"2024"占 2 格或 4 格视书写而定）
**不计入**：划线删除、涂黑覆盖、跨页装订线内文字、题号行外的空白行

> **术语统一**：报告用「稿纸占格数」指代格数推算值；「转写字符数」仅作对照；
> 二者不得混称"字数"。

### 校验：双通道比对

拿到两个数：
- **A = 稿纸占格数（格数推算值）**
- **B = 转写字符数**

| 偏差 | 判读 | 处理 |
|---|---|---|
| \|A−B\| / A ≤ 10% | 正常 | 取 **A** |
| 10% < 偏差 ≤ 25% | 转写有遗漏或涂改误计 | 取 **A**，报告中标注偏差 |
| 偏差 > 25% | 转写不可靠 | 取 **A**，该题**不判"超字数/字数不足"**，只提示复核 |

> **A 永远优先于 B**。手写转写必然漏字（尤其是连笔、行书），字符数系统性偏低。
> 用 B 判"字数不足"会冤判——这是手写批改最常见的错误。

### 超字数判定

- **无明确评分依据时**（官方标准/题干要求未写明超字扣分）：只报告稿纸占格数与超限幅度，**不自动扣分**，并在改进建议中给"删哪些话"的具体方案
- **有明确依据时**：按该标准执行，并在报告中注明依据来源
- 超限幅度较大时，无论是否扣分，都必须给删减方案——超字挤占的是踩点空间，这本身就是要修的问题

## 五、图像质量分诊

| 等级 | 判据 | 处理 |
|---|---|---|
| **清晰** | 每个字都能辨认，无阴影遮挡 | 正常批改 |
| **可读** | 90% 以上字可辨，个别模糊 | 正常批改，模糊处标 `[?]` |
| **勉强** | 60%-90% 可辨，成句模糊 | 批改但**降级结论强度**：只给档位不给精确分，或给分数区间 |
| **不可读** | <60% 可辨 | 该题不批改，请重拍（只重拍该页） |

**常见拍摄缺陷与对策**：

| 缺陷 | 影响 | 对策 |
|---|---|---|
| 倾斜（拍摄角度斜） | 行错位，跨行拼接错乱 | 按格线走向校正，逐行追踪而非逐水平线切 |
| 阴影/反光 | 局部字消失 | 该区域标 `[反光遮挡]`，**不推测内容** |
| 对焦不清 | 笔画粘连（"日/曰""未/末"） | 靠上下文判断，标 `[?]` |
| 只拍半页 | 跨页断句 | 明确说明"第 X 页右下角内容被裁切"，请补拍 |
| 多页重复 | 同一段出现两次 | 按内容去重，保留完整版本 |

## 六、申论语境下的高危形近字

以下字在申论材料中高频出现且易混，**遇到必须结合上下文确认，不确定标 `[?]`**：

| 易混组 | 辨识要点 |
|---|---|
| 部 / 陪 | "部门""部署" vs "陪同" |
| 绩 / 债 | "成效""业绩" vs "债务" |
| 措 / 错 | "举措""措施" vs "错误" |
| 振 / 震 | "振兴""提振" vs "震慑" |
| 融 / 溶 | "融合""融通" vs "溶解" |
| 治 / 冶 | "治理" vs "冶炼" |
| 制 / 製 | 简体一律"制" |
| 坚 / 艰 | "坚持""攻坚" vs "艰难" |
| 权 / 杈 | "权利""授权" vs 树杈 |
| 已 / 己 / 巳 | 三者易混，看开口方向 |

**原则：只转写确实看清的字。** 看不清就原位标 `〔?〕`（无法确认）或 `〔候选?〕`（有候选字），
不要静默填满——那会把识别误差变成用户的失分。中置信字可暂按候选义理解并评分，但**必须列入「待复核」且不据此扣分**（见 SKILL.md 第三节）。

## 七、整卷批改的版面信息采集

整卷照片除文字外，还要采集三类**非文字信息**，它们直接影响改进建议：

1. **答题区选择**——是否答在指定区域、是否超出答题框
2. **分段与分条**——小题是否分条（"一、二、三、"），大作文段落数
3. **书写密度**——字距是否过密（阅卷视觉疲劳）、是否写到格子外

> 这些**不单独扣分**（除非评分规则明确），但必须写进改进建议——
> 它们是"同样的内容为什么别人分高"的常见原因。
