# 教学型批改报告结构

**定位**：这份报告的目的不是"告诉你几分"，而是**让你下次遇到同类题时，能自己想到该想的东西**。

诊断型报告回答"我错了什么"；教学型报告回答三个问题：
1. **如何作答** —— 从题干到答案的操作步骤
2. **为什么这么作答** —— 每一步的依据（材料哪句、什么信号、什么判据）
3. **如何提高技巧** —— 能带到下一题的规则与自检清单

**硬性原则：每个结论都必须带依据。** 没有依据的建议一律不写。
- ❌ "结构要更清晰" → 无依据，不可执行
- ✅ "你第 2、3 条都是'加强宣传'的下位，属同层次应合并——材料第 5 段把两者并列在一句里" → 有依据

---

## 一、七段结构（顺序不可调）

```markdown
# {题型} · 教学复盘

> 分数放在最后一节（⑦），作参照而非结论；标题不写分数。

## 识别与假设

| 项 | 识别结果 | 来源 |
|---|---|---|

> 假设说明：{凡自动补全的项在此逐条列出}

## 手写答案转写（供核对）

> 以下为忠实转写，保留原分条与表述，未作润色。
> `〔?〕`＝无法确认；`〔候选?〕`＝候选识别；`〔划线删除〕`＝删除内容，不计入有效作答。

{逐条原文转写，保留原序号}

**转写情况**：正文共 N 条；存疑 X 处（详见末尾「待复核」）；涂改 Y 处。

## ① 题干解剖

| 项 | 内容 | 依据 |
|---|---|---|
| 题型 | 归纳概括 | 题干"概括"+"做法"，两个信号都指向概括题 |
| 要素 | 做法（单一要素） | 只问"做法"，不问成效，答成效不得分 |
| 范围 | 给定资料 2 | 题干限定"根据资料2" |
| 分值→字数 | 15 分 → 300 字 | 题干明示 |
| 命题意图 | 考"能否从具体做法中提炼上位概念" | 材料给的是一堆具体举措，没有现成概括词 |

**审题 60 秒口诀**：圈题型词 → 数要素 → 划范围 → 算字数 → 猜命题人想筛掉谁。

## ② 材料 → 答案的映射（本报告的核心）

**这张表就是"为什么这么作答"的全部答案。**

| 材料位置 | 原文关键句 | 识别信号 | 上位概括 | 必踩 |
|---|---|---|---|:---:|
| 资料2 第1段 | "建立村规民约，成立红白理事会，推行积分制" | 建立/成立/推行 = 做法动词 | **健全长效机制** | ✓ |
| 资料2 第2段 | "选派科技特派员驻村指导" | 选派/驻村 = 人力投入 | **强化人才支撑** | ✓ |
| 资料2 第3段 | "硬化道路、改造管网、新建文化广场" | 硬化/改造/新建 = 硬件投入 | **完善基础设施** | ✓ |
| 资料2 第4段 | "村民收入增长，满意度提升" | 增长/提升 = 成效，非做法 | ✗ 不答 | ✗ |

**读表方法**（这一段必须讲，否则表是死的）：
> 材料里全是具体做法时，**不要抄做法，要找它们的共同上位词**。
> 判据：如果三条做法能被一个词统摄（村规民约/理事会/积分制 → 都属"机制"），就用那个词；
> 如果统摄不了，才并列写。**上位词优先从材料里找，材料没有才自拟。**

## ③ 你的作答复盘：偏差定位

**不做逐句勾划**，只定位三类偏差，每类给"你当时的思路 vs 正确的思路"：

| 偏差类型 | 你的表现 | 你当时的思路（推测） | 正确的思路 |
|---|---|---|---|
| **漏点型** | 缺"健全长效机制" | 读到村规民约、理事会，觉得是"基层自治"，归到"治理"里去了 | 这三个词都是**制度性安排**，统一归"机制"，不是"自治" |
| **偏差型** | "加强硬件建设" | 想概括"硬化道路+改造管网"，自己造了个词 | 材料第3段末句有现成词"基础设施"，抄它 |
| **冗余型** | 写了"村民收入增长" | 觉得是成效，写上更完整 | 题干只问做法，写成效**不得分还占字数** |

> 偏差定位的价值在于：**漏点是"没看见"，偏差是"看见了想错"，冗余是"想多了"**。
> 三者练法完全不同——漏点练扫描，偏差练概括词，冗余练审题。

## ④ 三处关键决策复盘

挑 3 个真正影响分数的决策点（不是知识点罗列）：

**决策 1：这题要不要写总括句？**
- 常规做法：归纳概括题**不写**总括句，采分点全在具体举措上
- 本题判据：题干问"做法"，材料全是并列举措，没有统领性表述 → **不写**
- 反面情形：如果题干问"主要做法及其成效"，就需要一句总括把两类串起来

**决策 2：第 2、3 条该合并还是拆分？**
- 判据：**是否同一层级**。都是"投入"类（人才投入 / 硬件投入）→ 同一层级 → 可合并也可并列
- 但材料把它们写成两段、各有独立做法 → **分开写更安全**（阅卷按点给分，合并可能丢一半）

**决策 3：用"健全长效机制"还是"完善管理制度"？**
- 判据：**材料原词优先**。材料第1段末句写的是"长效机制"，直接用
- 自拟词的风险：阅卷人按关键词给分，"管理制度"可能不认

## ⑤ 可迁移技巧（带走能用）

**格式强制：必须是"看到 X → 就做 Y"，不能是"要注意 Z"。**

1. 看到「建立 / 成立 / 推行 / 完善 / 出台」→ 这类词后面跟的都是**制度性安排**，统一往上归"机制"。
2. 看到「选派 / 引进 / 培训 / 组建队伍」→ 归"人才支撑"。
3. 看到「硬化 / 改造 / 新建 / 配备」→ 归"基础设施"。
4. 材料里出现现成的概括性短语（常在段末）→ **优先抄它，别自拟**。
5. 题干只问一个要素时，**其他要素一律不写**，哪怕材料里有。

## ⑥ 考场自检清单（答完 60 秒过一遍）

- [ ] 每一条是不是**同一层级**？（有没有"机制"和"建了个理事会"混着写）
- [ ] 概括词是**材料原词**还是我自造的？（自造的要能说出为什么）
- [ ] 有没有把**成效**当成**做法**写？
- [ ] 有没有写题干没问的要素？
- [ ] 字数在限制的 85%–95% 吗？

## ⑦ 参考作答 + 分数

{正文，约 280 字}

### 白鹭版（结构随题干、要素分栏）
{正文，约 295 字}

**两版差异的本质**（不是换措辞）：
| | 小马哥版 | 白鹭版 |
|---|---|---|
| 组织逻辑 | 上位词统领具体做法 | 按材料段落顺序分栏 |
| 适合谁 | 容易漏点的人 | 要点齐但写得干的人 |

### 分数

**13 / 15**（86.7%）——放在最后，作参照而非结论。
{若失分集中在漏点，给一句：这道题的分数不代表你的水平，代表你这次扫描的覆盖率。}
```

## 二、大作文的教学版差异

大作文的"如何作答"不是采分点，是**立意与结构**。③④ 段替换为：

```markdown
## ③ 你的文章：立意与结构复盘

| 环节 | 你的处理 | 判据 | 结论 |
|---|---|---|---|
| 主题类型 | 双主题（守正/创新） | 题干两个关键词且互为对象 | AB 型 |
| 总论点 | "守正与创新缺一不可" | 是否回应两个关键词 | ✓ 成立 |
| 分论点1 | 守正是根基 | 是否服务于总论点 | ✓ |
| 分论点3 | 创新是动力 | **与前两段同层**（都是"A 重要"） | ✗ 应递进到"A+B" |

## ④ 三处关键决策复盘

**决策 1：为什么这是 AB 型不是 ABC 型？**
- 判据：题干只有两个词，且互为对象（守正的对象是创新，反之亦然）→ AB
- 若题干出现第三个"大目标"性质的词（如"社会文明"）→ 才是 ABC

**决策 2：分论点该怎么排？**
- AB 型模板：A→B / B→A / A+B
- 你写成了 A→B→A，第三段重复第一段 → 结构原地踏步

**决策 3：论证为什么显得单薄？**
- 你的第2段：举例（某企业创新）→ 结论
- 缺的一步：**分析**（"之所以…是因为…"）
- 判据：举例只能证明"存在"，分析才能证明"必然"
```

## 三、什么该删

教学型报告容易写胖。以下内容**一律不写**：

| 不写 | 原因 |
|---|---|
| 方法论介绍、"本报告基于…体系" | 用户要的是操作，不是背景 |
| 逐句勾划表（✓/✗/△ 全篇） | 教学场景下价值低，只保留偏差定位 |
| "表述可以更规范"这类无替换建议的评语 | 不可执行 |
| 错别字清单 | 手写场景辨字不可靠 |
| 大段范文赏析 | 只保留两版差异的**本质**（结构逻辑），不赏析文采 |
| 分数放在开头 | 分数是参照，不是结论 |

## 四、跨次积累：从"失分点"到"认知偏差"

错题库记录维度要跟着改：

| 旧（诊断型） | 新（教学型） |
|---|---|
| 记"漏了哪个采分点" | 记"**哪类信号词没识别出来**" |
| 记"表述不规范" | 记"**概括词自拟而非用材料原词**" |
| 记"结构不清晰" | 记"**同层级要点未合并**" |

> 差别在于：失分点是**这道题的**，认知偏差是**跨题的**。
> 只有后者能累积成能力曲线——"你在'制度类信号词'上已经连续 3 次漏点"才有训练价值。

复发提醒的话术也要改：

```
⚠️ 第 3 次了：你在「制度类信号词」（建立/完善/出台/推行）上连续漏点。
- 第1次：2026-10-20 归纳概括·基层治理
- 第2次：2026-10-23 归纳概括·乡村振兴
- 本次：...
这不是粗心，是**信号词库缺这一类**。练法：拿 3 套真题的材料，
只做一件事——把每段里"制度类动词"圈出来，不看题干，纯练扫描。
```
