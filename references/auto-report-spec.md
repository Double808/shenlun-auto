# 诊断型批改报告结构（降级模式）

> ⚠️ **这不是默认结构。** 默认走教学结构 `teaching-report-spec.md`（七段，讲"怎么想"）。
> 本文只在用户明确说「只要分数」「快速看下」「不用讲方法」时使用。
>
> 诊断结构的定位：**回答"我错了什么"**，不回答"下次怎么才对"。
> 如果用户是备考状态（而非只想验分），用错了结构等于没帮上忙。

**固定八段，顺序不可调。** 用户只看前两段就能知道分数，看第三到五段知道怎么改。

## ⑤ 改进建议

**1. 必补的失分点（按提分幅度排序）**

- **缺"健全长效机制"（-3 分，最要命）**

**2. 表述升级**

**4. 结构建议**：{分条是否清晰、是否漏总括句、条与条是否同层次}

## 二、整卷模式差异

多题合并时，在**每题的完整报告之前**加一段总览，**每题仍保留完整八段**（可压缩④⑤）：

```markdown
# 申论整卷批改 · {试卷名}

## 全卷概览

| 题号 | 题型 | 得分 | 得分率 | 主要问题 |
|---|------|:---:|:---:|---|
| 1 | 归纳概括 | 11/15 | 73% | 漏 2 点 |
| 2 | 综合分析 | 12/15 | 80% | 总括句缺失 |
| 3 | 大作文 | 28/40 | 70% | 分论点论证单薄 |
| **合计** | — | **51/70** | **73%** | — |

**本卷最该先解决的一件事**：{一句，指向得分率最低且可短期改善的项}

---
（以下逐题展开）
```

## 三、大作文的段落替换

大作文用同一骨架，但 ③④ 段替换为：

```markdown
## ③ 四类文定档

| 判据 | 你的文章 | 判定 |
|---|---|---|
| 主题类型 | 双主题（守正 / 创新） | AB 型 |
| 是否跑题 | 未跑题 | ✓ |
| 标题 | "守正创新，行稳致远" | 合规 |
| 开头 | 引出主题 + 亮明总论点 | ✓ |
| 分论点 | 3 个，但第 3 段与前两段同层 | △ |
| 分论点论证 | 举例为主，缺分析 | ✗ |

**定档：三类文上（28/40）** —— 框架成立，卡在论证深度。

## ④ 提分路径（按投入产出排序）

- 从 28 → 32（二类文）：只需补第 3 段的层次（把"A+B→C"改成"C 的两个侧面"）
- 从 32 → 36（一类文）：第 2、4 段各加 1 句分析性语句（"之所以…是因为…"）
```

## 四、写作纪律

| 必须 | 禁止 |
|---|---|
| 第一行给分数 | "我来帮你分析一下" |
| 分数用真实分值 | 百分制、只给得分率 |
| 改进建议给"改成什么" | "表述不够规范"这类空话 |
| 手写场景不给错别字表 | 逐字挑错 |
| 识别存疑单独列出 | 把识别误差算作失分 |
| 参考作答两版结构不同 | 两版只换措辞 |
| 假设显式标注 | 悄悄替用户补分值 |
